# Local LLM Config

This repository provides configurations for running local Large Language Models
(LLMs) with the [Pi coding agent](https://pi.dev) and
[llama.cpp](https://github.com/ggml-org/llama.cpp).

The models are tuned for an AMD Strix Halo computer with 64 GB of memory.
The [AMD Strix Halo Llama.cpp Toolboxes](https://github.com/kyuz0/amd-strix-halo-toolboxes)
comes highly recommended for setting up an inference environment for the same.

## Repository Structure

- `agent/`: Pi coding agent configuration.
- `models/`: llama.cpp model configuration files.
